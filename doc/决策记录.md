## 7. 关键约束（不可突破）

| 约束 | 出处 |
|---|---|
| `Iso.TILE_W/H = 64/32` 与世界逻辑不改 | 适配方案 §1.1 红线 |
| 可见格数恒定 900（面积归一），`zoom` 无下限夹紧 | 适配方案 §6.1 |
| `stretch/scale_mode = fractional`，窗口 7 档上限 1440p | 适配方案 §6.1/§7.2 |
| 横屏锁 `handheld/orientation=0` | `project.godot` |
| 暂停用「原因集合」（设置/后台/手动），最后一个释放才恢复 | 适配方案 §7.7 |
| 数值一律进 `data/`，脚本不硬编码平衡值 | 项目结构说明 §1 |
| 跨模块只走 `EventBus`，禁止跨层 `get_node` | 项目结构说明 §1 |
| 每功能必须可被 headless 断言 | 项目结构说明 §5 |
