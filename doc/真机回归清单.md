# 真机回归清单（阶段 D 新增内容）

> 目的：本轮的改动集中在**触控热区**、**场景切换**、**弹层**三类，这三类在 headless 验收里看不出问题，必须在真机上点一遍。
> 每条都给了「操作 / 期望 / 异常时先看什么」，按顺序做，10 条大约 10 分钟。

## 0. 前置

```powershell
# 1) 装导出模板（一次性）：编辑器 → 编辑器 → 管理导出模板 → 下载并安装 4.7.2
# 2) 出包 + 装 + 起 + 看日志（一条命令）
powershell -NoProfile -ExecutionPolicy Bypass -File tools/deploy_android.ps1
```

如果只想重装不重编：加 `-NoBuild`；只看日志：`-NoBuild -NoInstall`。

## 1. 主菜单

| 项 | 内容 |
|---|---|
| 操作 | 冷启动 App |
| 期望 | 直接进主菜单（不是游戏场景）；标题「等距 RPG」居中；四个按钮纵向排列，**全部在安全区内**（刘海/手势条不压边） |
| 异常先看 | 按钮被裁 → 安全区 insets 是否为 0（`adb logcat -s godot` 里搜 `[Display]` 一行，看 `insets=`）；标题英文 → `locale.cfg` 是否残留 en |

## 2. 新游戏

| 项 | 内容 |
|---|---|
| 操作 | 点「新游戏」 |
| 期望 | 进游戏；玩家在地图中央出生；HUD 左上角显示「生命 120/120 魔法 30/30」；顶部显示「任务：猎狼 0/3」 |
| 异常先看 | 黑屏 → 场景切换失败；血条只有一半 → `HpFill` 宽度未随安全区重算 |

## 3. 移动 + 主操作

| 项 | 内容 |
|---|---|
| 操作 | 左手摇杆移动，右手点 ATK 攻击最近的狼 |
| 期望 | 摇杆跟手、不漂移；点怪后玩家自动接近并攻击；命中飘数字且**有音效** |
| 异常先看 | 点怪无反应 → 是否点在了树的遮挡区（拾取只认屏幕矩形内候选） |

## 4. 技能按钮（本轮新增热区）

| 项 | 内容 |
|---|---|
| 操作 | 锁定一只怪，点右侧「技能」 |

| 异常先看 | 环不动 → `get_skill_cooldown_left` 未接；按钮点不到 → 与 ATK 热区重叠（ATK 在 y[-204,-68]，技能在 y[-330,-194]，检查是否被摇杆抢事件） |

## 6. 五页签面板（本轮改动）

| 项 | 内容 |
|---|---|

## 9. 传送门换图（本轮重点）

| 项 | 内容 |
|---|---|
| 操作 | 走到地图上方传送点（发光圆环），站上去 |
| 期望 | 切到第二张图（更小、布局不同）；玩家状态保留（等级/背包/血量）；**切图后 ATK 与技能键立刻可用**；不会立刻被弹回 |
| 异常先看 | 攻击失灵 → 换图信号重连回归（本轮已修，若复现请立即反馈）；来回弹 → 落点距对方门口 <24px |

## 10. 存档 / 读档

| 项 | 内容 |
|---|---|
| 操作 | 收集几件物品后，面板「存档」页存到槽 1；退出 App；重开 → 主菜单「读取存档」槽 1 |
| 期望 | 金币/背包/装备/等级/任务进度/所在地图都恢复；血量为存档时的值；主菜单槽位摘要显示金币数 |
| 异常先看 | 读档后位置错乱 → 存档 `map` 字段与当前地图不一致；槽位显示「空」→ CRC 校验失败（logcat 搜「存档校验失败」） |

|---|---|

## 记录方式

发现异常时，最少给我这三样：

1. 第几条（例如「9 换图」）
2. 现象一句话（例如「切图后点 ATK 没反应」）
3. `adb logcat -s godot:V` 里对应的最后 20 行

有这三样我能直接定位；只有「有问题」三个字的话，我得先猜是哪一层。

## 已知限制（不是 bug）

- **没有 BGM**（Q16 决定只做 SFX），所以安静是预期行为。
- **低端机档位未验证**（Q06=B 但无真机），若在你的机器上掉帧，先去设置里把画质档调到 low。
- **图纸缩放**：世界层在 0.7~1.0 渲染倍率下会轻微模糊，这是 linear + mipmap 的预期表现，不是采样错误。
