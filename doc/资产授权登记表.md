## 1. 允许的来源

| 来源 | 允许 | 附加要求 |
|---|---|---|
| 自绘 | ✅ | 无 |
| 3D 渲染（Blender/Blockbench 自建模型） | ✅ | 记录工程文件路径 |

| 来源不明 / 拆包提取 | ❌ | 禁止 |

| 验收 | 4 向朝向 / 脚底原点 / 描边 / 色板 / 无缝（勾选通过的项） |

## 4. AI 资产的轻修验收（5 条，全部通过才可进包）

1. 4 向齐全且朝向正确（等距 45°，NE/NW/SE/SW）。
2. 原点在脚底，画布尺寸符合 `doc/ui/移动端多分辨率适配方案.md` §3.8 规格。
3. 描边宽度与既有资产一致。
4. 主色不超过风格基准图的色板。
5. 地面类可无缝拼接；图集内不渗色（缩放到 0.7 渲染倍率下检查）。

不满足者退回 3D 渲染管线重出，不得以「再修一版」无限迭代。
