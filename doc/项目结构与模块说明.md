# 项目结构与模块说明

> 适用版本：Godot 4.7（GDScript，GL Compatibility，横屏移动端）
> 更新日期：2026-10-29

## 1. 整体架构

项目是「数据驱动 + 程序化绘制」的等距（iso）RPG 原型，分层如下：

| 层 | 目录 | 职责 |
|---|---|---|
| 全局服务层 | `autoload/` | 单例：配置、输入、本地化、显示适配、事件总线、暂停状态 |
| 数据层 | `data/` | 纯 JSON 配置（角色、敌人、地图、文案、交互映射），脚本不硬编码数值 |
| 场景层 | `scenes/` | 场景树装配：启动、世界视口、地图、角色、UI |
| 逻辑层 | `scripts/` | 按模块分组的行为脚本，与 `scenes/` 保持同层级同名对应 |
| 表现层 | `scripts/*/*_visual.gd`、`scripts/combat/` | 占位视觉、飘字、特效，全部 `draw_*` 程序化绘制，零贴图 |
| 资源层 | `fonts/` | 全局字体（霞鹜文楷 Lite）+ 授权文件 |
| 工程资产 | `tests/`、`tools/` | 验收测试与开发工具，**不参与游戏运行、不进包** |
| 本地素材 | `refs/` | 参考图，仅本机留存，不入库、不入包 |

数据流：`data/*.json` → `DataRegistry`（启动时载入校验）→ 场景/控制器读取；UI 文案统一 `Locale.t()`；跨模块通信只走 `EventBus` 信号，不跨层 `get_node("../../..")`。

## 3. 命名与分组规范

| 规范 | 约定 |
|---|---|
| 目录 | 小写、单数、按模块划分（`enemy/` 而非 `enemies/`） |
| 脚本文件 | `snake_case.gd`；类名 `PascalCase`（`class_name UiButton`） |
| 场景文件 | 与驱动脚本同名同层级：`scenes/ui/hud.tscn` ↔ `scripts/ui/hud.gd` |
| 占位视觉 | `*_visual.gd`，同一模块的表现层后缀固定 |
| 测试 | `tests/<模块>_check.gd` + 同名 `.tscn`，退出码表示结果 |
| 数据 | `data/<模块>/<名称>.json`，键名 `snake_case` |
| 提交 | 脚本的 `.uid` 一并提交；`.godot/`、`build/`、`refs/`、`mytest/` 不入库 |

## 4. 进包与不进包

`export_presets.cfg`（`export_filter="all_resources"`）配合排除规则：

```text
exclude_filter="tests/*,tools/*,refs/*,mytest/*"
```

| 目录 | 入库 | 进包 | 说明 |
|---|---|---|---|
| `autoload/ scripts/ scenes/ data/ fonts/` | 是 | 是 | 游戏运行必需 |
| `tests/ tools/` | 是 | 否 | 只在本机跑，避开包体膨胀 |
| `refs/` | 否 | 否 | 参考图，仅本机留存 |
| `mytest/` | 否 | 否 | 与本工程无关的插件草稿与日志，可直接删除 |
| `.godot/ build/` | 否 | 否 | 导入缓存与导出产物 |

## 5. 验收方式

```bash
# 单个验收（无头）
godot --headless --path <项目> res://tests/<name>_check.tscn
# 资源重新导入
godot --headless --path <项目> --import
# 导出并核对包内容
godot --headless --path <项目> --export-debug "Android" build/android/iso_rpg.apk
```

修改目录或脚本路径后，必须重跑：`--import` → 全部 `*_check` → 导出并检查 `assets/` 内是否出现意外的目录。

## 6. 已知事项

1. `scenes/ui/hud.tscn` 带 UTF-8 BOM，编辑器扫描时会报 `Parse Error: Expected '[',`（运行期正常），建议去掉 BOM。
2. `display_preset_check` 与 `touch_contract_check` 各有历史失败断言（UI 缩放上限 1.3 vs 1.2、暂停原因集合），与目录调整无关。
3. 字体若做子集化：OFL 保留字体名条款要求改名，且需同步 `fonts/NOTICE.txt`。
